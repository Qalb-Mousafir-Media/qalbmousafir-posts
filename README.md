# Qalb Mousafir · قلب مسافر — médias

Vidéos de la chaîne Qalb Mousafir (TikTok, puis Instagram, Facebook, YouTube), leurs scripts et le moteur qui les produit.

## Dossiers

| Dossier | Contenu |
|---|---|
| `videos/` | Vidéos finales compressées, publiées via Metricool |
| `episodes/` | Scripts JSON relus (texte à l'écran, narration, graphies pour la voix) |
| `legendes/` | Légendes TikTok, couvertures et commentaires à épingler |
| `docs/` | Brief, format des scripts, règles religieuses et relectures, plan de croissance, plan communauté |
| `tools/` | Moteur de rendu, vérifications, polices (OFL) |
| `audio/` | Nachids libres de droits (sans instruments) |

## Règles

- Uniquement des points qui font consensus entre les écoles sunnites, et des hadiths authentiques avec leur référence (voir `docs/BRIEF.md`).
- Chaque script passe par une relecture religieuse indépendante avant le rendu.
- Rien n'est publié sans l'accord de Karim.
